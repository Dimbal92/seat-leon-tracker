MY SEAT LEON — PK70 XTU

Open index.html in a browser to use locally. Data is saved in that browser on that device.

To install on iPhone as a web app: upload the contents of this folder to GitHub Pages (or another HTTPS host), open the HTTPS link in Safari, tap Share > Add to Home Screen and turn on Open as Web App.

The MOT and DVLA buttons open official government services. They DO NOT retrieve live expiry dates. After checking them, enter those dates into the app. A government API integration requires approved credentials and a secure backend.

Expense tracking, CSV/JSON backup and per-reminder calendar files are available. Imported calendar alerts depend on calendar app settings. No automatic background push alerts and no cross-device syncing.
